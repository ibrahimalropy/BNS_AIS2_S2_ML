What is included?

Notebook → preprocessing → tuned pipelines → FastAPI service → this GitHub-hosted project page.

How the project works

01 · CleanOutlier masking, duplicate removal, missing-value imputation, and engineered diet indices.
02 · TransformRobust scaling, log transforms for consumption variables, ordinal encoding, and one-hot encoding.
03 · TrainStratified train/test split and GridSearchCV with F1 scoring for three classification pipelines.
04 · ServeFastAPI endpoints are included in the repository for local or Python-host deployment.
